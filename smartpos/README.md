# smartpos

POS backend: product catalog, warehouse, receipts.

Stack: Java 21, Spring Boot 3.3.5, PostgreSQL, MongoDB, ClickHouse, Kafka, RabbitMQ, Redis, MinIO, Liquibase, OpenFeign, Apache POI, Telegram Bot API, MapStruct, Maven.

Run:

```bash
./mvnw spring-boot:run
```

Settings come from environment variables.
